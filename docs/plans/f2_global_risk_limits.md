# F2. 글로벌 리스크 한도 설계 문서

## 1. 개요
급격한 시장 변동성이나 연쇄 매매로 인한 과도한 손실을 방지하기 위해, 사용자별 리스크 관리 한도(종목별 최대 노출액, 일일 최대 주문 건수, 일일 최대 손실액)를 도입하고 주문 발행 직전에 실시간 검증합니다.

## 2. 세부 설계
1. **사용자 환경 설정 (`UserManager.DEFAULT_PREFERENCES`)**:
   - `max_ticker_exposure_krw`: 종목별 최대 노출액 (None: 무제한). 종목의 미체결 매수 잔여액 + 현재 보유 평가액 합산 기준.
   - `daily_max_order_count`: 일일 최대 주문 발행 건수 (None: 무제한). 당일 자정(KST) 이후 발행된 주문 건수 기준.
   - `daily_max_loss_krw`: 일일 최대 손실 허용액 (None: 무제한). 당일 실현 손실액 합산 기준.
2. **검증 게이트 (`core.trading_gate.assert_risk_limits`)**:
   - 신규 매수 주문 및 일반 주문 발행 직전에 호출.
   - **보호성 매도(손절, `strategy == "stoploss"`)는 한도 검사에서 완전 면제**되어 항상 즉시 체결 가능.
   - 한도 초과 시 `RiskLimitExceededError` 발생 -> 사용자에게 친절한 사유 메시지 전달 및 주문 차단.
3. **수용 기준 (Acceptance Criteria)**:
   - 종목별 노출액 초과 시 신규 매수 차단.
   - 일일 주문 건수 초과 시 신규 주문 차단.
   - 손절(`stoploss`) 주문은 한도 초과 상태에서도 정상 발행 허용.
   - 기본값(None)일 때는 기존과 동일하게 무제한 허용.
