# supabot-manager 전면 프론트엔드 아키텍처 및 화면 재설계 마스터 플랜

## 1. 전면 재설계 개요 및 비전

### 1.1 배경 및 문제 진단
현재 `supabot-manager`는 백엔드 기능이 확장되면서 프론트엔드 화면에 수많은 지표, 11개 이상의 리포트 탭, 복합 가로 아코디언 필터, 빽빽한 설정 폼이 누적되었습니다.
- **인지 과부하 (Cognitive Overload)**: 첫 화면에서 봇이 지금 정상인지, 얼마의 수익/손실이 났는지, 어떤 주문이 체결 대기 중인지 3초 안에 판단하기 어려움.
- **모바일/PC 경험의 부조화**: 모바일에서는 스크롤 길이가 과도하고 터치 조작이 불안정하며, PC 와이드 스크린에서는 넓은 화면을 효율적으로 쓰지 못하고 1열로 나열됨.
- **인터랙션 파편화**: 화면마다 버튼 스타일, 뱃지 색상, 로딩 처리(단순 스피너 vs 덜컹거림)가 달라 시스템의 일관성과 신뢰도가 저하됨.

### 1.2 마스터 비전: "Pro-Trading Density & Glanceable Simplicity"
1. **모바일: 토스·업비트급의 극단적 간결함 (Mobile First Simplicity)**
   - 초기 진입 시 스크롤 없이 핵심 현황 파악 (Glance UI).
   - 복잡한 필터와 설정은 제스처 기반 바텀시트(Bottom Sheet)로 숨기고, 필요할 때만 노출.
2. **PC: 블룸버그·트레이딩뷰급의 모듈형 워크벤치 (PC Pro Density)**
   - 1280px+ 와이드 화면에서 3열 그리드(자산/차트 - 봇 관제 - 실시간 체결) 지원.
   - 한눈에 전체 포지션과 주문 흐름을 관제할 수 있는 다단 분할 뷰.
3. **무결점 비즈니스 로직 유지**:
   - 기존의 모든 백엔드 엔드포인트(FastAPI), 웹소켓/폴링 훅(`useRealtime`), 인증/세션 체계는 100% 보존하면서 프론트엔드 프레젠테이션 계층을 완전히 새로 작성.

## 2. 정보 구조 (IA: Information Architecture) 전면 개편

기존 8개 라우트의 역할을 명확히 재정의하고, 중복 및 산만한 메뉴를 통합합니다.

```
[supabot-manager Navigation Map]
├── 1. 대시보드 (/dashboard) ──── 3초 헬스체크 + 자산 요약 + 3컬럼 모듈 관제
├── 2. 주문 관리 (/orders) ────── [활성 주문 워크벤치] vs [주문 히스토리 아카이브] (듀얼 뷰)
├── 3. 거래 내역 (/trades) ────── 실시간 체결 타임라인 + 거래 규모/손익 티커
├── 4. 전략 스튜디오 (/templates) ─ 시각적 파라미터 빌더 + 프리뷰 차트 + 템플릿 카드 라이브러리
├── 5. 리포트 센터 (/reports) ─── 3대 허브 통합 (자산 포트폴리오 / 성과 & MDD / 트레이딩 분석)
├── 6. 시스템 관제 (/admin) ───── 봇 런타임 텔레메트리 + 유저 권한 + 이벤트 스트림 (Admin 전용)
├── 7. 설정 (/config) ────────── 개인화 디스플레이 + 보안(MFA/TOTP) + 알림 설정
└── 8. 인증 (/login) ──────────── 미니멀 보안 로그인 + 2FA 원클릭 인증
```

### 네비게이션 구조 비교
- **데스크톱 (PC)**:
  - 좌측 슬림 독(Dock) 사이드바 (64px 아이콘 모드 ↔ 220px 확장 모드).
  - 상단 글로벌 헬스 바: 봇 실시간 상태(펄스 인디케이터), 전체 주문 긴급 킬스위치, 프로필/테마 스위처.
- **모바일 (Mobile)**:
  - 하단 고정 4버튼 내비게이션: `[홈(대시보드)] [주문] [리포트] [전체메뉴]`.
  - 기존의 복잡한 5개 핀 고정 + 드래그 재정렬 로직을 걷어내고, "전체메뉴" 탭 시 세련된 슬라이드업 바텀시트로 즉시 모든 기능 접근.

## 3. 디자인 시스템 2.0 (Design Tokens & Foundations)

### 3.1 핀테크 컬러 팔레트 (FinTech Palette)
- **배경 & 서피스 (Dark First / High-Contrast)**:
  - Root Canvas: `bg-slate-950` (#020617)
  - Card Surface: `bg-slate-900` (#0f172a) / 보더: `border-slate-800` (#1e293b)
  - Elevated Popover / Sheet: `bg-slate-850` (#131c31) / 보더: `border-slate-700/60`
- **손익 표기 표준 (한국형 vs 글로벌 테마 지원)**:
  - 기본(한국형): 수익/상승 = `text-red-500` / 손실/하락 = `text-blue-500`
  - 글로벌 옵션: 수익 = `text-emerald-500` / 손실 = `text-rose-500`
- **거래소 고유 브랜드 컬러 뱃지**:
  - Upbit: `bg-blue-950/60 text-blue-400 border-blue-800/50`
  - Bithumb: `bg-amber-950/60 text-amber-400 border-amber-800/50`
  - KIS: `bg-sky-950/60 text-sky-400 border-sky-800/50`
  - Toss: `bg-indigo-950/60 text-indigo-400 border-indigo-800/50`

### 3.2 타이포그래피 & 수치 전용 폰트
- 일반 텍스트: `Noto Sans KR` (가독성 중심).
- 금융/금액/수량/수익률: `font-mono` (숫자 폭이 일정한 타뷸러 폰트 `font-mono tabular-nums`)를 적용하여 테이블 정렬 시 흔들림 방지.

### 3.3 마이크로 인터랙션 및 피드백 표준
- **스켈레톤 로딩(Skeleton Loading)**: 스피너 회전으로 인한 레이아웃 깨짐 제거, 카드 및 테이블 형태의 펄스 플레이스홀더 기본 탑재.
- **낙관적 UI (Optimistic Updates)**: 주문 취소/실행 시 즉시 상태를 '요청 중'으로 전환하고 토스트 알림 연동.
- **햅틱/시각적 버튼 반응**: 누름 효과(`active:scale-95`), 호버 트랜지션 통일.

### 4.2 대시보드 (Dashboard)
- **개념**: "3초 안에 현재 투자 상태와 봇 상태를 파악하는 글랜스 관제탑"
- **모바일 화면**:
  1. **최상단 통합 히어로 카드**:
     - 총 평가자산 (예: `₩34,850,000`)
     - 당일 실현+평가 손익 (`+₩1,240,000 (+3.68%) ▲`)
     - 최근 7일 자산 성장 스파크라인 (미니 Area 차트)
  2. **핵심 퀵 메트릭 (2x2 미니 그리드)**:
     - 투자 원금 | 활성 오픈 주문 수 | 24h 실현손익 | 봇 루프 지연시간
  3. **세그먼트 탭 [보유 자산 | 최근 체결]**:
     - 탭 1 (보유 자산): 거래소별 상위 코인/주식의 평가금액 및 손익률 랭킹.
     - 탭 2 (최근 체결): 방금 체결된 주문 타임라인.
- **PC 와이드 화면 (3-Column Workbench)**:
  - **Left (50%)**: 대형 누적 손익 추이(30일) + 자산 배분 비중(도넛 & 프로그레스) + 전체 보유 종목 테이블.
  - **Center (25%)**: 봇 시스템 헬스 모니터(CPU/메모리, 각 거래소별 API 연결 핑, 미체결 대기열 현황).
  - **Right (25%)**: 실시간 체결 티커 피드(최근 15건) + 긴급 킬스위치 제어 센터.

### 4.3 주문 관리 (Orders) — 듀얼 워크벤치
- **개념**: "즉시 대응이 필요한 주문(활성)과 분석 대상(히스토리)의 완벽한 분리"
- **구조**:
  - `[Tab 1: 활성 주문 (Open Orders)]`:
    - 대기(`wait`), 부분체결(`partial`), 재주문대기(`pending_reorder`), 예약(`reserved`) 건만 모음.
    - 상단 액션 바: `[선택 동기화]` `[전체 일괄 취소]` `[선택 주문 취소]`.
    - 실시간 체결률 프로그레스 바 + 체결 수량 / 잔여 수량 직관적 비교.
    - 모바일: 카드를 좌로 밀면(Swipe Left) 즉시 취소 확인창 호출.
  - `[Tab 2: 주문 이력 (Order History)]`:
    - 체결완료(`done`), 취소(`cancel`) 내역.
    - 검색(종목명, 배치 번호) + 거래소 필터 + 기간 선택기.
    - 모바일: '통합 필터' 버튼 1개로 바텀시트를 띄워 깔끔하게 필터링.
    - CSV 다운로드 지원.

### 4.4 거래 내역 (Trades)
- **개념**: "실시간 체결 모니터링 & 거래 규모/수수료 분석"
- **개편 사항**:
  - 상단: 당일 총 거래대금, 매수/매도 비율 바(Bull/Bear ratio bar), 총 거래 건수 요약.
  - 리스트:
    - 시간, 거래소, 종목, 매수/매도(색상 명확화), 체결단가, 체결수량, 총 거래금액.
    - 클릭 시 해당 거래의 상세 모달(체결 시각, 주문 UUID, 관련 수수료) 호출.
  - 모바일에서는 타임라인 스트립 형태로 시각화하여 언제 어떤 종목이 체결되었는지 한눈에 파악.

### 4.5 전략 템플릿 스튜디오 (Templates)
- **개념**: "복잡한 파라미터 입력을 시각적 마법사(Wizard)로 탈바꿈"
- **개편 사항**:
  - **템플릿 카드 뷰**:
    - 등록된 전략 템플릿(RSI 거미줄, 그리드, 볼린저밴드 등)을 카드 형태로 진열.
    - 카드 내에 [적용 거래소, 종목, 매수/매도 구간, 1회 예산, 원클릭 실행 버튼] 포함.
  - **비주얼 전략 빌더 (Visual Strategy Builder Modal)**:
    - 1단계: 거래소 & 종목 선택 (자동완성 및 현재가 실시간 표기).
    - 2단계: 전략 유형 선택 (Grid / Smart Grid / RSI 조건식).
    - 3단계: 가격/RSI 범위 설정 시 **미니 시각화 차트**에 매수/매도 라인이 시각적으로 프리뷰됨.
    - 4단계: 예산 및 주문 분할 수 설정 후 저장 및 즉시 모의실행.

---

### 4.6 리포트 센터 (Reports) — 3대 분석 허브
- **기존 11개 탭의 복잡성을 3개 직관적인 허브로 통폐합**:
  1. **포트폴리오 자산 (Portfolio)**:
     - `현재 투자중(Holdings)` + `자산 배분(Allocation)` 결합.
     - 가상자산/국내주식/해외주식/현금 비중 파이 차트 + 거래소별 비중 + 종목별 수익률 랭킹.
  2. **수익 & 리스크 성과 (Performance & Risk)**:
     - `실현 손익` + `일별/월별 손익` + `MDD(Drawdown)` 결합.
     - 듀얼 인터랙티브 차트: 상단은 누적 수익률 곡선, 하단은 고점 대비 낙폭(언더워터 MDD 차트).
     - 깃허브 잔디 스타일의 **'손익 캘린더 히트맵'** (초록/빨강 강도로 일별 수익 시각화).
  3. **트레이딩 인텔리전스 (Trading Intelligence)**:
     - `전략별 분석` + `거래소별 분석` + `거래 페어` + `승률/손익비(Win Rate / Profit Factor)`.
     - 각 전략별(RSI, Grid 등) 기대 수익률과 승률 비교 차트.

---

### 4.7 시스템 관제 & 관리자 (Admin)
- **개념**: "봇 시스템 전체의 런타임 텔레메트리 관제 센터"
- **3대 서브 모듈**:
  1. **시스템 헬스 (System Health)**:
     - 봇 백엔드 프로세스 가동 시간(Uptime), 루프 지연시간(Latency ms), 에러 카운트.
     - 거래소별 WebSocket 및 REST API 레이트 리밋 상태.
  2. **유저 & 권한 관리 (User Management)**:
     - 등록 유저 목록, 권한(Admin/User), 승인 상태, 계정 비활성화 토글.
  3. **실시간 이벤트 & 로그 스트림 (Live Events)**:
     - 봇 내부 시그널 발생, 주문 접수, 체결, 취소, 오류 로그를 필터링 가능한 터미널 뷰로 제공.

---

### 4.8 개인화 및 환경설정 (Config)
- **개념**: "트레이더 취향에 맞춘 디스플레이 & 철통 보안 설정"
- **설정 항목**:
  1. **화면 표시 설정 (Display)**:
     - 테마 (다크 모드 / 라이트 모드 / 시스템 연동).
     - 손익 컬러 프리셋 (한국형: 빨강-상승/파랑-하락 vs 글로벌: 초록-상승/빨강-하락).
     - 기본 글꼴 및 폰트 크기 슬라이더 (실시간 미리보기 제공, 로컬 스토리지 즉시 반영).
     - 로그인 후 첫 화면 설정 (대시보드 / 주문 / 리포트).
  2. **보안 설정 (Security)**:
     - TOTP/MFA 2단계 인증 등록/해제.
     - 현재 세션 및 로그인 이력 확인.

## 5. 프론트엔드 아키텍처 및 상태 관리 고도화

### 5.1 컴포넌트 디렉토리 리팩토링 구조

### 5.2 반응형 훅 (`useBreakpoint`)
- 단일 Tailwind `md:`(768px) 기준 외에, JS 레벨에서 디바이스 특성을 감지하여 컴포넌트 렌더링을 지능적으로 전환:
  - `isMobile`: 터치 친화적 제스처, 바텀시트, 카드 스택 활성화.
  - `isDesktop`: 단축키(ESC 모달 닫기, 스페이스바 새로고침 등), 툴팁, 다단 그리드 활성화.

## 6. 마스터 구현 로드맵 (6단계)

| 단계 | 목표 | 주요 산출물 | 기간 |
|---|---|---|---|
| **Phase 1** | **디자인 시스템 & 기반 컴포넌트 구축** | - 신규 토큰(컬러/폰트/서피스) 정의<br>- `BottomSheet`, `SegmentedControl`, `Skeleton` 공통 모듈 제작 | 1주차 |
| **Phase 2** | **AppLayout & 내비게이션 전면 교체** | - 모바일 4키 하단바 + 전체메뉴 바텀시트<br>- PC 슬림 사이드 독 + 글로벌 헬스 탑바 | 2주차 |
| **Phase 3** | **대시보드(Dashboard) 3컬럼 & 히어로 카드** | - 모바일 통합 히어로 카드 & 스파크라인<br>- PC 3컬럼 워크벤치 (자산 - 관제 - 실시간체결) | 3주차 |
| **Phase 4** | **주문(Orders) & 거래(Trades) 듀얼 워크벤치** | - 활성 주문(Open) vs 주문 이력(History) 탭 분리<br>- 모바일 필터 바텀시트 & 스와이프 액션<br>- 체결 타임라인 뷰 | 4주차 |
| **Phase 5** | **리포트(Reports) 3대 허브 통폐합** | - 포트폴리오 자산 허브 (배분+보유)<br>- 수익&리스크 허브 (듀얼 차트 + 잔디 히트맵)<br>- 트레이딩 인텔리전스 허브 | 5주차 |
| **Phase 6** | **전략 스튜디오 & 시스템 관제/설정 마무리** | - 시각적 전략 빌더 마법사<br>- 시스템 헬스 텔레메트리 대시보드<br>- E2E 반응형 QA 및 성능 최적화 | 6주차 |
